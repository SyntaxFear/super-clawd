# Super Clawd

A retro platformer starring Clawd, the Claude Code mascot. Fix bugs, collect tokens and ship to prod.

> Fan game. Not affiliated with Anthropic.

## Play

```bash
npm install
npm run dev
```

Open http://localhost:5180.

## Controls

|                       | Keyboard          |
| --------------------- | ----------------- |
| Move                  | ← → / A D         |
| Jump                  | ↑ / Space / Z / W |
| Run + throw subagents | Shift / X         |
| Crouch, enter pipes   | ↓ / S             |
| Pause                 | Esc / P / Enter   |
| Mute                  | M                 |

## Development

```bash
npm test
npm run build
```
